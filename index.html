🎯 Project Objective

Develop an end-to-end Machine Learning regression system to forecast food delivery turnaround times (ETA in minutes) for logistics platforms like Zomato and Swiggy.

⚙️ Machine Learning Pipeline

  • Data Sanitization: Stripped string artifacts (e.g. (min) and conditions ), handled null values, and corrected negative GPS coordinate logging errors.
  • Spatial Feature Engineering: Converted latitude and longitude pairs into accurate physical distance in kilometers using the spherical Haversine Formula.
  • Scikit-Learn Pipeline: Categorical features encoded with OneHotEncoder, numerical metrics normalized with StandardScaler.
  • Model Serialization: Pretrained pipeline saved via joblib and lightweight client engine embedded for instant zero-server deployment.

💡 Top Predictors Discovered

  • Courier Rating (24.97%): Top-rated delivery partners complete orders significantly faster.
  • Transit Distance (16.77%): Direct physical determinant of travel time.
  • Road Traffic Density (14.41%): Severe delays during Jam vs unimpeded Low traffic.
  • Courier Age (13.57%): Correlates with delivery stamina and navigation experience.
